# Hark Android fork

This fork targets Android only. Keep Google sign-in through Better Auth, a Node/SQLite backend, and direct FCM delivery. Expo is the local app framework; EAS and Expo Push Service are not required.

Run project commands through `direnv exec "$PWD" ...` after the flake is available. Native Android output is generated by Expo prebuild: put maintained native code in local modules and config plugins, not generated `apps/expo/android` files.

Use an explicit `adb -s SERIAL` and reuse the task's emulator.

The base `https://sietch.sole-pierce.ts.net` endpoint belongs to T3. Hark is served at `https://hark.sole-pierce.ts.net` through Tailscale Services. Preserve every existing Tailscale Serve mapping and do not enable Funnel.

Keep credentials outside Git and frontend environment variables. Disable upstream deployment/publishing workflows before pushing this fork. Agents own only their assigned files; the coordinator owns dependency installation, lockfile integration, commits, deployment and final checks unless explicitly delegated.

See `docs/android-implementation.md` for protocol and ownership decisions.
